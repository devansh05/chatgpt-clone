# chatgpt-clone
A Chatgpt clone app.
A fullstack NextJS major focused on logic building for Ai.
Tech Stack:
1. NextJS
2. Prisma + Neon
3. TailwindCSS
4. Ai SDK (Vercel) + OpenAi
5. Clerk Authentication

Features:
1. Authentication using clerk
2. Automatically initialized chat when user opens the app
3. Chat history with context
4. Chat responses with streams
5. New chat option
